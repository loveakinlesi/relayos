Scaffold a basic `relayos.config.ts` file with commented-out examples and next steps.

## Usage

```sh
relay init [--force]
```

## Options

| Flag | Default | Description |
|------|---------|-------------|
| `--force` | false | Overwrite an existing `relayos.config.ts` |

## Next steps

1. Install the plugins you want:
   ```sh
   pnpm add relayos @relayos/postgres @relayos/stripe stripe @relayos/nextjs
   ```

2. Wire the config into your framework (Next.js example):
   ```ts
   // app/api/relay/[...all]/route.ts
   import { toNextJsHandler } from '@relayos/nextjs';
   import { relay } from '@/relayos.config';

   export const { POST } = toNextJsHandler(relay);
   ```

3. Uncomment a plugin and register a handler with `relay.on(...)`.

4. When ready for persistence, uncomment the Postgres lines, create a database, and run:
   ```sh
   DATABASE_URL=postgres://localhost:5432/myapp relay migrate
   ```

See the [full Quickstart](/docs/quickstart) for more.

## Functions

### createRelay

```ts
function createRelay<const TPlugins extends readonly RelayPlugin<any>[] = []>(
  config: RelayConfig<TPlugins> = {},
): Relay<EventMapOf<TPlugins>>;
```

Creates a RelayOS runtime instance. This is the main entry point for developers: register event handlers via `relay.on()`, receive provider webhooks through `relay.handler`, and configure persistence via `config.database`. The relay's event types are inferred from the plugins you register—typed plugins make `relay.on()` autocomplete event names and narrow event payloads.

## `relayos/next-js`

Next.js support is a subpath export of this package - no separate install.

| Export | Kind | Description |
|--------|------|-------------|
| `toNextJsHandler` | Function | Adapts a relay to a Next.js App Router catch-all route handler. |

```ts
function toNextJsHandler<TEventMap extends Record<string, unknown>>(
  relay: Relay<TEventMap>,
): {
  POST: (req: Request, ctx: { params: Promise<{ all: string[] }> }) => Promise<Response>;
};
```

Adapts a relay instance to a Next.js App Router catch-all route. Returns an object with a `POST` handler that integrates the relay's webhook handler. Uses only web-standard `Request`/`Response` plus Next.js's promise-shaped route `params`—no `import from 'next'` is required.

```ts
// app/api/relay/[...all]/route.ts
import { toNextJsHandler } from 'relayos/next-js';
import { relay } from '@/relayos.config';

export const { POST } = toNextJsHandler(relay);
```

Provider webhooks are then received at `/api/relay/<provider>` (e.g., `/api/relay/stripe`).

## Functions

### createRelay

```ts
function createRelay<const TPlugins extends readonly RelayPlugin<any>[] = []>(
  config: RelayConfig<TPlugins> = {},
): Relay<EventMapOf<TPlugins>>;
```

Creates a RelayOS runtime instance. This is the main entry point for developers: register event handlers via `relay.on()`, receive provider webhooks through `relay.handler`, and configure persistence via `config.database`. The relay's event types are inferred from the plugins you register—typed plugins make `relay.on()` autocomplete event names and narrow event payloads.

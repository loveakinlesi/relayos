## Install

```sh
pnpm add @relayos/nextjs
```

Peer dependency: `@relayos/core`

## Exports

| Export | Kind | Description |
|--------|------|-------------|
| `toNextJsHandler` | Function | Adapts a relay to a Next.js App Router catch-all route handler. |

## Functions

### toNextJsHandler

```ts
function toNextJsHandler<TEventMap extends Record<string, unknown>>(
  relay: Relay<TEventMap>,
) {
  return {
    POST: async (req: Request, ctx: NextRouteContext) => Promise<Response>;
  };
}
```

Adapts a relay instance to a Next.js App Router catch-all route. Returns an object with a `POST` handler that integrates the relay's webhook handler. Uses only web-standard `Request`/`Response` plus Next.js's promise-shaped route `params`—no explicit `next` import is needed beyond the route context type hints.

## Usage

Create a catch-all route at `app/api/relay/[...all]/route.ts`:

```ts
import { createRelay } from 'relayos';
import { stripe } from '@relayos/stripe';
import { toNextJsHandler } from '@relayos/nextjs';
import { createPostgresExecutionStore } from '@relayos/postgres';
import { createDb } from '@relayos/postgres';

const relay = createRelay({
  database: createPostgresExecutionStore(createDb(process.env.DATABASE_URL!)),
  plugins: [stripe({ webhookSecret: process.env.STRIPE_WEBHOOK_SECRET! })],
});

relay.on('stripe.charge.succeeded', async (event, ctx) => {
  await ctx.step.run('process_charge', async () => {
    // handle charge
  });
});

export const { POST } = toNextJsHandler(relay);
```

Provider webhooks are now received at `/api/relay/<provider>` (e.g., `/api/relay/stripe`).

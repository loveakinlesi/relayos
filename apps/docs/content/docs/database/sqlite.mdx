---
title: SQLite
description: Use better-sqlite3 for local development and small deployments.
---

Pass a `better-sqlite3` database straight into `restaq({ database })`.
Restaq detects the dialect automatically and applies its own schema
migrations.

<Tabs items={['pnpm', 'npm', 'yarn', 'bun']}>
  <Tab value="pnpm">
  ```sh
  pnpm add better-sqlite3
  ```
  </Tab>
  <Tab value="npm">
  ```sh
  npm install better-sqlite3
  ```
  </Tab>
  <Tab value="yarn">
  ```sh
  yarn add better-sqlite3
  ```
  </Tab>
  <Tab value="bun">
  ```sh
  bun add better-sqlite3
  ```
  </Tab>
</Tabs>

```ts
// relay.ts
import { restaq as createRestaq } from 'restaq';
import Database from 'better-sqlite3';

export const restaq = createRestaq({
  database: new Database('restaq.db'),
  plugins: [
    // ...
  ],
});
```

Good for local development, testing, and small single-instance deployments.
Once you're running more than one instance of your app, move to
[Postgres](/docs/database/postgres) or [MySQL](/docs/database/mysql) instead.
